# 独立游戏开发素材、音频与工具导航手册

> 整理与提供：Amiya_desi（源自 Amiya的书桌资源导航 https://nav.sayori.org 与 https://blog.sayori.org）

本清单从 200+ 条日常创作书签中精选出最适合高校游戏开发社团与 Game Jam 团队使用的免费/开源资源站。

---

## 一、2D / 3D 游戏素材与着色器

- **Kenney Assets**（https://www.kenney.nl/assets/）
  - 被称为“独立游戏界的慈善家”，海量 CC0 无版权限制的 2D/3D/UI/音频素材包。
- **OpenGameArt**（https://opengameart.org/）
  - 老牌开源游戏素材社区，下载时注意查看单条素材的 CC-BY 或 CC0 协议说明。
- **Godot Shaders**（https://godotshaders.com/）
  - 专为 Godot 引擎准备的 2D/3D 着色器代码库（水体、描边、像素化、CRT 滤镜、故障特效等）。
- **itch.io Free Game Assets**（https://itch.io/game-assets/free）
  - 全球独立创作者分享的像素角色、瓦片地图（Tileset）与 UI 素材总入口。
- **Game-icons.net**（https://game-icons.net/）
  - 数千枚可自定义配色导出的 SVG/PNG 技能与物品图标（通常为 CC-BY 协议，需署名）。
- **Quaternius & KayKit**（https://quaternius.com/ / https://kaylousberg.itch.io/）
  - 风格统一、自带基础动画的 CC0 低多边形（Low-Poly）3D 角色与场景资产包。
- **Poly Haven**（https://polyhaven.com/）
  - 高质量 CC0 3D 模型、PBR 材质贴图与 HDRI 环境光库。

## 二、像素美术、动画与原型草图工具

- **Piskel**（https://www.piskelapp.com/）— 浏览器端直接绘制像素画与序列帧动画。
- **LibreSprite**（https://libresprite.github.io/）— 经典像素画软件 Aseprite 的免费开源分支。
- **Pixelorama**（https://orama-interactive.itch.io/pixelorama）— 使用 Godot 引擎编写的开源像素动画编辑器。
- **Lospec**（https://lospec.com/palette-list）— 像素画入门教程与经典像素调色盘（Palette）宝库。
- **Laigter**（https://azagaya.itch.io/laigter）— 为 2D 精灵图一键生成法线贴图，让 2D 游戏拥有动态光影体积感。
- **Excalidraw**（https://excalidraw.com/）— 手绘风格在线白板，适合团队头脑风暴、绘制关卡灰盒与状态机草图。

## 三、游戏音乐（BGM）与音效（SFX）

- **PeriTune**（https://peritune.com/）— 高品质免费 BGM，涵盖奇幻、日常、战斗与悬疑风格，适合 RPG 与视觉小说。
- **DOVA-SYNDROME & 魔王魂 & 甘茶の音楽工房**（https://dova-s.jp/ / https://maou.audio/ / https://amachamusic.chagasi.com/）— 日本三大免费游戏配乐与音效素材库。
- **Freesound**（https://freesound.org/）— 全球协作环境音、动作音与机关音效库（可按 CC0 协议筛选）。
- **jsfxr & ChipTone**（https://sfxr.me/ / https://sfbgames.itch.io/chiptone）— 在线一键生成跳跃、拾取、爆炸、受击等复古 8-bit 游戏音效并导出 WAV。
- **BeepBox & Bosca Ceoil**（https://www.beepbox.co/ / https://boscaceoil.net/）— 零乐理门槛的轻量级游戏循环音乐（Loop BGM）制作工具。

## 四、素材合规与署名规范

根据《幻造工坊社团安全管理细则》第四章第十九条：
1. 项目使用的素材、字体、音乐、代码与插件须为原创或具备明确授权许可。
2. 下载外部素材时，请同步在项目文档中记录：**素材名称、作者、来源 URL、许可证类型（如 CC0 / CC-BY 4.0 / MIT）**。
3. 完整在线导航请访问：https://nav.sayori.org/
